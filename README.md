# Aaron Zhang Data MCP

Paid MCP tools for AI agents (x402, USDC on Base): sourced OpenAI/Anthropic fundamentals and comparison, Bitcoin/Lightning changes and releases, BIP and EIP status, Ethereum client and AI agent framework releases, x402 protocol updates.

- Endpoint: https://aaron-zhang-mcp.vercel.app/mcp (streamable HTTP, stateless). `list_datasets` is free.
- Clients pay per call with an x402-capable MCP client, e.g. `@x402/mcp` (`createx402MCPClient`).
- Same data over plain HTTP: preipo-feed.vercel.app, btc-radar.vercel.app, aaron-protocol-radar.vercel.app.
